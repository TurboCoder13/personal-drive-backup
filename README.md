# Personal Drive Backup

Public information pages for a private Google Drive backup tool.

- [Homepage](https://turbocoder13.github.io/personal-drive-backup/)
- [Privacy policy](https://turbocoder13.github.io/personal-drive-backup/privacy/)

This repository contains only the public website. It does not contain backup data, credentials, or operational configuration.

## Hosting

Static HTML and CSS, hosted on GitHub Pages from the root of the main branch. No build dependencies or third-party scripts.
