Personal Drive Backup

A private offsite backup tool operated by TurboCoder13. It uses rclone to maintain backups in an authorised Google Drive account.

Google Drive access

The tool requests Google Drive access so it can list, read, upload, update and delete files as needed to maintain and verify backups. Access is granted by the Google account holder through Google's consent screen.

This tool is for the operator's own backup use and is not available for public registration.
