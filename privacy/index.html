Privacy policy

For Personal Drive Backup. Last updated: 22 October 2026.

Purpose and data access

This private tool uses rclone and the Google Drive API to maintain offsite backups for its operator. It accesses file contents, names, folder structure and associated metadata as needed to list, transfer, update, delete and verify backup files. The requested Drive permission can allow access beyond the backup folder.

Storage and access

Backup data is transferred between the operator's systems and the authorised Google Drive account. Access credentials are retained securely for ongoing authorised backup access. The operator and authorised administrators use this information to operate and troubleshoot the backup. Operational logs may include file names, paths and transfer errors.

Use and sharing

Google user data is used only to operate and maintain the backup. It is not sold, used for advertising or used to train AI models. Google processes data as the Drive storage and authentication provider. This public website does not receive OAuth tokens or backup contents.

Retention and deletion

Backup files remain until removed by the operator or the configured backup process. Deleted files may remain in Google Drive Trash until it is emptied or Google deletes them. Operational logs and credentials remain on the operator's systems until rotated or removed.

Revoking access

The account holder can revoke this tool's access in Google Account connections. Revocation stops future authorised access; it does not delete existing backups. The operator can separately remove backup files, stored credentials and logs.

Website hosting and contact

These information pages are hosted by GitHub Pages. They contain no analytics scripts, advertising or sign-in form. GitHub may process visitor connection information as described in its privacy statement.
